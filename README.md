# Personal Expense Tracker

## Project Overview

This is an Excel-based Personal Expense Tracker created to record, analyze, and visualize personal expenses.

The project contains 70 expense transactions with details such as date, category, description, amount, and payment mode.

## Features

- Daily expense tracking
- Total spending calculation
- Average spending calculation
- Highest and lowest expense
- Category-wise spending analysis
- Payment-mode analysis
- Date-wise spending analysis
- Spending charts and visualizations

## Excel Functions Used

- SUM
- AVERAGE
- MAX
- MIN
- SUMIF

## Visualizations

- Spending by Category
- Spending by Payment Mode
- Daily Spending Trend

## Tools Used

- Microsoft Excel
- GitHub
